
📦 Inventory Manager – C++17

A console-based Inventory Management System developed in C++17 by DariTech.

A beginner-to-intermediate programming project designed to manage products, track stock quantities, search inventory, and calculate total stock value.

🚀 Features

- Add Products: Add new products with automatically assigned IDs.
- View Inventory: Display all products with their IDs, quantities, and prices.
- Search Products: Search products by name (case-insensitive).
- Update Stock: Change the quantity of existing products.
- Delete Products: Remove products with confirmation.
- Low Stock Report: Find products at or below a specified stock level.
- Stock Value: Calculate the total inventory value.
- Data Persistence: Save inventory data automatically in a text file.

🛠️ Technologies Used

- C++17
- Standard Template Library (STL)
- Vectors
- Structures
- Functions
- File Handling
- Input Validation

💻 Installation & Usage

1. Clone the repository

git clone https://github.com/faizmuhebbi135-rgb/Inventory-Manager-CPP.git

2. Open the project directory

cd Inventory-Manager-CPP

3. Compile the program

g++ -std=c++17 -Wall -Wextra -pedantic inventory_manager.cpp -o inventory_manager

4. Run the program

Linux / macOS:

./inventory_manager

Windows:

.\inventory_manager.exe

💾 Data Storage

The program stores inventory information in "inventory.txt".

Product changes are saved automatically after successful add, update, and delete operations.

🎯 Project Purpose

This project was developed as a practical C++ learning project to improve programming skills and understand how inventory management systems work.
